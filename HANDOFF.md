# DrillHarmony: передача проекта в новую сессию (мобильное приложение)

Архив `drillharmony-source_18.zip` содержит полный исходный код сайта drillharmony.com. Положение на 16.10.2026.
Цель новой сессии: сделать мобильное приложение DrillHarmony на основе сайта.

## Владелец и продукты
- Сайт drillharmony.com, оператор ИП Шайсламова А. В., почта info@drillharmony.com.
- Продукты: **SlideX** (учёт слайда и ориентирования), **Tempo** (анализ времени и режимов бурения),
  **Etude** (обучение инженеров ННБ, тренажёр и ИИ-наставник). Владелец работает в Башнефтегеофизике (БНГФ).

## Обязательные правила (действуют и для приложения)
1. Не использовать расчёты и разработки, защищённые чужим авторским правом. Только своё или открытые источники.
   Если найдёте на сайте что-то похожее на чужое — сообщить владельцу.
2. Никаких выдуманных новостей, кейсов, клиентов, отзывов, статистики. Никаких выдуманных ссылок на Telegram.
3. Ничего, что создаёт репутационный риск.
4. WITS Bridge не делаем вообще (проект отменён).
5. Тексты не должны выглядеть сгенерированными ИИ: без шаблонных фраз, длинных тире через слово, «Разберём…»,
   заголовков вида «Тема: пояснение».
6. Название в выдаче и брендинге: **DrillHarmony.com** / DrillHarmony. Форум называется «Форум DrillHarmony».
7. Пользователи форума не должны видеть, какая модель отвечает за бота. Это знает только администратор.
8. Персональные данные граждан РФ хранятся в РФ (152-ФЗ). Трансграничная передача сейчас не ведётся.
   Политика: `site/privacy.html`. Любые новые данные в приложении (аккаунты, аналитика, push) отразить в политике.

## Что есть на сайте (источник контента для приложения)
- `site/calculators/` — 23 инженерных калькуляторов: траектория, инклинометрия, бурение, давление, раствор, единицы.
  Список и группы: `tools/calc.py` (CNAV). Логика расчётов в собранных JS в `site/assets/j/` и в `src/js/calc-*.js`.
- `site/articles/` — 36 материалов по ННБ, плюс глоссарий и русско-английский словарь (`articles/dictionary`).
- `site/tools/` — LAS-просмотрщик (`src/js/las-viewer.js`), 3D-траектория (`traj-tool.js`),
  калькулятор скрытого НПВ (`npt-cost.js`).
- `site/play/` — игра «Посади горизонталь» (`src/js/play.js`).
- `site/tests/`, `site/tasks/` (задача недели), `site/career/`, `site/cheatsheet/`.
- Страницы продуктов: `site/slidex/`, `site/tempo/`, `site/etude/`; заказчикам: `pilot/`, `buy/`, `security/`; `about/`.
- Заявки с сайта: `site/lead.php` (SMTP из `lead-config.php`, пример в `lead-config.example.php`).
- Иконки: `site/icon-192.png`, `icon-512.png`, `favicon.svg`; `site.webmanifest` (сейчас display: browser).

## Форум (`site/forum/`)
PHP 8 + SQLite (`forum/_data/forum.sqlite`), маршруты через `.htaccess` → `index.php?r=…`.
- 17 разделов (ННБ, бурение, ГТИ, сообщество), база знаний 16 справок + 5 справок ГТИ, 23 темы для обсуждения.
- Регистрация, вход, подтверждение e-mail, восстановление пароля, сессии с cookie на `/forum/`, CSRF.
- Редактор: markdown-подобная разметка, рендер на сервере (`render()` в `lib.php`), картинки в `forum/uploads/`.
- Бот (`bot.php`): ответы по материалам сайта через GigaChat / YandexGPT / OpenAI-совместимый API, очередь `bot_queue`.
- **JSON API для приложения пока нет.** Есть только `upload` (JSON) и `preview` (HTML). Для мобильного клиента
  форума нужно добавить API (например `r=api/...`) с токенами вместо cookie-сессий.

## Сборка сайта
```
cd tools && python3 mk_calcs.py && python3 mk_art2.py && python3 mk_tests.py && python3 mk_tools.py \
  && python3 mk_forum.py && python3 links.py && cd .. && python3 build.py --zip
```
`build.py` минифицирует `src/js`, `src/css` (esbuild), подставляет хеши вместо `@name.js`/`@name.css`, собирает
`dist/`, sitemap (lastmod из `lastmod.json`) и поисковый индекс. Подробнее: `README-build.md`.
При изменениях на сайте sitemap должен обновляться (делает build.py).

## Дизайн
Тёмная тема по умолчанию, фон `#080d10`, акцент янтарный (`--amber`), шрифты в `site/fonts/`.
Токены и переопределения: `src/css/theme.css`. Основной текст на сайте выровнен по ширине.

## Варианты для мобильного приложения (решить в новой сессии)
- PWA на основе сайта: быстрее всего, калькуляторы работают офлайн.
- Обёртка (Capacitor) над тем же кодом: публикация в RuStore / Google Play / App Store.
- Нативное приложение (React Native / Flutter): калькуляторы офлайн, статьи, форум через новый API, push.
Перед публикацией в магазинах: политика конфиденциальности для приложения, учёт требований RuStore.

## Мобильное приложение (16.10.2026)
Папка `app/`: Capacitor 8, Android и iOS из одного кода. Инструкция: `app/README-app.md`.
- 40 расчётов: 22 с сайта (те же скрипты) и 18 только в приложении (`app/shell/newcalcs.js`: растворы, ГТИ,
  потери давления при циркуляции, отклонение от плана, отход). Формулы из открытых источников, перечислены в файле.
- 20 интерактивных моделей из статей, инструменты, тесты, задача недели, игра, справочник (глоссарий и словарь).
- Профили скважин (подставляются в расчёты), история расчётов, избранное, размер текста, тёмная и светлая тема.
- Своя палитра приложения (графит, золотистый янтарь знака, бирюзовые значения), знак DrillHarmony без ®.
- `python3 app/mk_app.py` собирает `app/www` из `dist/`; `cd app && npm run setup` создаёт `android/` и `ios/`.
- В политике п. 8.3 о мобильном приложении.
- Не сделано: статьи и форум внутри приложения (открываются в браузере), API форума, push.
- 16.10.2026 найден похожий продукт БУРОН (buronpro.com, Android, продавец Барскова А. И.). У них ничего не заимствовано.
