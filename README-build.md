# DrillHarmony — сборка сайта

Структура:
- `site/` — страницы и готовые ассеты (HTML правится здесь);
- `src/js`, `src/css` — читаемые исходники нового кода (шапка, главная, WITSML, модели статей и калькуляторов);
- `tools/` — генераторы статей (`mk_witsml.py`, `mk_new.py`, `mk_viz.py`, `page.py`) и рендер иллюстрации героя (`hero.html`);
- `build.py` — сборка в `dist/`.

Сборка: `python3 build.py --zip` (нужен esbuild). Скрипт минифицирует `src/`, даёт файлам имена по хешу
содержимого (браузер не возьмёт старую версию из кеша), подключает общий стиль и меню на все страницы,
пересобирает `sitemap.xml` и индекс поиска `search.json` и упаковывает `dist/` в zip для загрузки на хостинг.

В HTML исходник подключается как `assets/j/@имя.js` или `assets/c/@имя.css` — сборка подставит хеш.

## sitemap.xml
Карта сайта собирается заново при каждой сборке из всех `index.html` — новые страницы попадают в неё сами,
удалённые исчезают. Дата `lastmod` меняется только у страниц, у которых изменился видимый текст: хеши текста
хранятся в `lastmod.json` (держите этот файл вместе с исходниками, иначе все даты станут сегодняшними).

## Порядок генерации
`cd tools && python3 mk_calcs.py && python3 mk_art2.py && python3 mk_tests.py && python3 mk_tools.py && python3 links.py && cd .. && python3 build.py --zip`

## Форум (/forum/)
PHP 7.4+ с PDO SQLite (на REG.RU есть по умолчанию). База создаётся сама при первом открытии: `forum/_data/forum.sqlite`
(папка закрыта от просмотра). Почта для подтверждения и восстановления пароля берётся из `lead-config.php`.
- Учётная запись владельца: **DrillHarmony** (e-mail info@drillharmony.com). Пароль задаётся через «Забыли пароль?»
  на странице входа или одноразово через `setup_key` в `forum/forum-config.php` (см. forum-config.example.php).
- Разделы и база знаний (16 справок) создаются при установке. Шаблон страниц (`forum/layout.html`) собирает
  `tools/mk_forum.py` из шапки и подвала сайта, сборка подставляет имена ассетов.
- Разделы, база знаний (16 справок + 5 справок ГТИ) и 23 темы для обсуждения создаются при установке
  и при обновлении старой базы (миграция по `PRAGMA user_version`, уже существующие темы не дублируются).
- Редактор сообщений: панель форматирования, вкладка «Просмотр», картинки (кнопка, Ctrl+V, перетаскивание).
  Картинки пересохраняются без EXIF, до 1800 px, лежат в `forum/uploads/ГГГГММ/`. Нужен модуль PHP GD
  (на REG.RU включён). Папку `uploads` при обновлении сайта не удаляйте, в архив сайта она не входит.
- Резервная копия форума — файл `forum/_data/forum.sqlite` и папка `forum/uploads`. При обновлении сайта `_data` не удаляйте.

### Бот форума
Пользователь «Бот DrillHarmony». Отвечает на новые темы в разделах из `bot.sections` (через ~20 с), в остальных,
если за `delay_hours` никто не ответил, и на сообщения с «@бот». Использует материалы сайта и базы знаний.
- Модель задаётся в `forum/forum-config.php`, блок `bot` (пример в forum-config.example.php):
  `provider` = gigachat (ключ авторизации из личного кабинета developers.sber.ru), yandex (API-ключ и folder_id
  из Yandex Cloud) или openai (любой совместимый API, `base_url`). Без ключа бот отвечает подборкой ссылок.
- Какая модель отвечает, видит только администратор: «Модерация» → блок «Бот». Названия моделей в ответах заменяются.
- Ответы готовятся в фоне после загрузки страницы. Для надёжности добавьте в cron хостинга раз в 5 минут:
  `curl -s "https://drillharmony.com/forum/cron.php?key=<содержимое forum/_data/secret.key>"`
- Политика конфиденциальности (п. 5.3) описывает российского провайдера модели. Если подключите зарубежный API,
  это трансграничная передача: нужно изменить п. 5.3–5.4 политики и уведомить Роскомнадзор.
