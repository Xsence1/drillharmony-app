# Приложение DrillHarmony для Android и iOS

На главном экране 9 разделов: траектория, инклинометрия, бурение и КНБК, гидравлика (БРД), буровые растворы,
ГТИ, инструменты, модели, обучение. Всё работает без интернета.

- **40 расчётов.** 22 с сайта: те же скрипты, результаты совпадают с сайтом. 18 только в приложении
  (`shell/newcalcs.js`): разбавление и смешивание растворов, объём ёмкости по уровню, реология (ПВ, ДНС, n, K),
  соотношение фаз РУО, твёрдая фаза по реторте, эффективность очистки, влажность шлама, расход реагента,
  производительность насоса, долив при подъёме, запаздывание шлама, d-экспонента, поровое давление по Итону,
  окно бурения, потери давления при циркуляции (степенная модель), отклонение от плана, отход и VS.
  Формулы из открытых источников, они перечислены в начале файла и в блоке «Как считается» каждого расчёта.
- **20 интерактивных моделей** из статей сайта, 3D-траектория из таблицы, LAS, НПВ, перевод единиц, шпаргалка,
  тесты, задача недели, игра.
- **Профиль скважины.** Конструкция, КНБК, раствор и магнитная модель вводятся один раз и подставляются во все
  расчёты (поля отмечены точкой). Скважин может быть несколько.
- **История.** Кнопка «В историю» сохраняет исходные данные и результат, из истории расчёт открывается с теми же
  значениями.
- **Справочник** терминов и русско-английский словарь, избранное, недавние, поиск.
- **Оформление.** Тёмная и светлая темы, три размера текста. Результат закреплён сверху и виден при вводе,
  поля стоят сеткой в три колонки, схема и пояснения свёрнуты.

Данные никуда не отправляются, аккаунтов, аналитики и push нет. Это записано в п. 8.3 политики
(`site/privacy.html`). Если в приложении появятся аккаунты форума или уведомления, политику нужно дополнить.

Оформление: официальный знак DrillHarmony и палитра сайта (тёмный фон `#080d10`, акцент `#f5a524`).
Токены в `shell/app.css`.
Знак ® не ставится, пока товарный знак не зарегистрирован.

## Состав

| Файл | Назначение |
|---|---|
| `mk_app.py` | собирает `www/` из готового сайта `dist/` |
| `shell/` | код и стили приложения: главный экран, профиль, история, справочник, `newcalcs.js` с расчётами приложения |
| `www/` | готовая веб-часть (уже собрана, можно сразу переходить к шагу 2) |
| `resources/` | иконка и заставка в палитре приложения |
| `scripts/setup-native.mjs` | создаёт и настраивает проекты `android/` и `ios/` |
| `capacitor.config.json` | id `com.drillharmony.app`, название, цвета |

## 1. Обновить веб-часть после правок сайта

```
cd app
npm run www
```
Нужны Python 3 с `beautifulsoup4` и esbuild, как для сборки сайта.

## 2. Создать проекты Android и iOS

Нужен Node.js 22 или новее.

```
cd app
npm run setup
```
Скрипт ставит Capacitor 8, создаёт `android/` (и `ios/` на Mac), генерирует иконки и заставки,
проставляет версию из `package.json`, отключает облачную резервную копию на Android и фиксирует
портретную ориентацию.

## 3. Android

Нужна Android Studio Otter (2025.2.1) или новее, в ней уже есть JDK 21 и Android SDK.

```
npx cap open android
```
- проверка на телефоне: включить отладку по USB, нажать Run;
- APK для рассылки коллегам: Build → Build APK(s), файл в `android/app/build/outputs/apk/debug/`;
- для RuStore и Google Play: Build → Generate Signed App Bundle / APK. Ключ подписи (`.jks`)
  хранить отдельно и не терять: без него обновление в магазине не выпустить.

## 4. iOS

Нужен Mac с Xcode 26 или новее и учётная запись Apple Developer.

```
npm run setup        # на Mac создаст ios/
npx cap open ios
```
В Xcode: App → Signing & Capabilities → выбрать команду. Run для проверки, Product → Archive для
отправки в App Store Connect.

## Публикация

- **RuStore**: аккаунт разработчика (ИП), подписанный APK или AAB, ссылка на политику
  `https://drillharmony.com/privacy.html`, скриншоты.
- **Google Play**: в анкете «Безопасность данных» указать, что приложение не собирает данные.
  Новые личные аккаунты обязаны провести закрытое тестирование перед публикацией, условия смотрите
  в консоли Play на момент подачи.
- **App Store**: в App Privacy выбрать «Data Not Collected». В Info.plist уже стоит
  `ITSAppUsesNonExemptEncryption = false`.

Скриншоты для магазинов удобно снимать в эмуляторе: главный экран, калькулятор с результатом,
3D-траектория, светлая тема.

## Новая версия

1. Поднять `version` в `package.json` (например 1.0.1).
2. `npm run www && npm run setup`.
3. Собрать подписанную сборку и загрузить в магазины.
