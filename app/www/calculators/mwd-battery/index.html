Как считается

Средний ток I = s·Iцирк + (1 − s)·Iпокой, где s — доля времени с циркуляцией. Ресурс T = C·(1 − k)/I, где C — ёмкость, k — потеря ёмкости от температуры и разряда большим током.

Литиевые батареи при высокой температуре и больших токах отдают меньше паспортной ёмкости, поэтому поправку k берут из данных производителя батареи для вашей температуры. Токи по режимам указаны в паспорте телесистемы. Значения по умолчанию только для примера.
