Поровое давление по Итону

Поровое давление по dc, сопротивлению или интервальному времени относительно нормального тренда.

Как считается

Eaton (1975): Pп = S − (S − Pн)·(X)ᵏ. Для dc и сопротивления X = наблюдаемое/нормальное, k = 1,2. Для интервального времени X = нормальное/наблюдаемое, k = 3,0.

Давления выражены в эквиваленте плотности. Горное давление берут из интегрирования плотностного каротажа, если его нет — региональный градиент.
