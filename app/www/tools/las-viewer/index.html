Просмотр LAS онлайн

Откройте файл LAS прямо в приложении: планшет с ГК, сопротивлением, нейтроном и плотностью, свои дорожки и шкалы, значения на любой глубине и картинка для отчёта. Файл не загружается на сервер, всё читается на вашем устройстве.

Откройте LAS-файлилиLAS 1.2 и 2.0, кодировки UTF-8 и Windows-1251. Файл остаётся у вас.

Окно

Наведите на планшет, чтобы увидеть значения. Колесо прокручивает, Ctrl + колесо меняет масштаб, перетаскивание сдвигает.

Дорожки

Кривые распознаются по мнемоникам автоматически: ГК, сопротивление, нейтрон, плотность, PEF, каверномер. Кривые и шкалы можно поменять, до трёх кривых на дорожку.

Кривые в файле

Что такое LAS

LAS (Log ASCII Standard) — открытый текстовый формат каротажа, который поддерживает Канадское общество каротажа (CWLS). Файл состоит из секций: ~V — версия, ~W — скважина и диапазон глубин, ~C — список кривых с единицами, ~P — параметры, ~A — сами данные столбцами.

~Curve information DEPT.M : Measured depth ← мнемоника.единица : описание GR .GAPI : Gamma ray ~A 2400.0 105.3 ← значения в порядке ~C
  • NULL в секции ~W задаёт значение «нет данных», обычно −999.25. Просмотрщик его не рисует.
  • WRAP YES означает, что строка данных разбита на несколько строк файла. Просмотрщик читает и такие файлы.
  • Кодировка. Российские программы часто пишут LAS в Windows-1251, названия скважин и описания кривых откроются правильно.

Как называются кривые телесистемы и каротажа и как их сопоставлять, рассказано в статье WITSML с нуля, раздел «Мнемоники ННБ».
