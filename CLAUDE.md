# DrillHarmony: сайт и мобильное приложение

Репозиторий: приватный `Xsence1/drillharmony-app`. Здесь лежит и сайт drillharmony.com (`site/`, `src/`, `tools/`, `build.py`,
собранный `dist/`), и мобильное приложение (`app/`). Основная работа сейчас идёт в приложении, версия в `app/package.json`.

## Правила владельца (обязательны)
1. Никаких расчётов и разработок под чужим авторским правом. Только своё или открытые источники, источник указывать
   в блоке «Как считается». Если что-то похоже на чужое, сообщить владельцу.
2. Никаких выдуманных новостей, кейсов, клиентов, отзывов, статистики, ссылок на Telegram.
3. Ничего, что создаёт репутационный риск.
4. WITS Bridge не делаем.
5. Тексты не должны выглядеть сгенерированными: без шаблонных фраз, длинного тире через слово, «Разберём…»,
   заголовков вида «Тема: пояснение». Интерфейс и тексты на русском.
6. Бренд: DrillHarmony.com / DrillHarmony, знак ® не ставить. Форум называется «Форум DrillHarmony».
7. Пользователи форума не должны видеть, какая модель отвечает за бота.
8. Персональные данные остаются в РФ (152-ФЗ). Любой новый сбор данных в приложении (аккаунты, аналитика, push)
   сначала описать в `site/privacy.html`, п. 8.3. Сейчас приложение ничего не отправляет.

Подробная передача контекста по сайту и форуму: `HANDOFF.md`.

## Устройство приложения
Capacitor 8, `appId` `com.drillharmony.app`. Веб-часть `app/www/` генерируется, руками её не править.

| Путь | Что там |
|---|---|
| `app/mk_app.py` | сборщик `app/www/` из `dist/`: переносит расчёты сайта в макет приложения, строит главный экран, 20 моделей, справочник (`ref.js`), копирует `shell/` |
| `app/shell/home.js` | главный экран и вкладки: Расчёты, Скважина (профиль), История, Справочник, Ещё. Навигация через hash `t=`/`s=` |
| `app/shell/app.js` | общее: тема, размер текста, профиль скважины, история, копировать/поделиться/сохранить, InAppBrowser для онлайн-данных и форума |
| `app/shell/fx.js` | анимации (переключатель «Анимации и 3D»), 3D-сцена, клавиатурная панель над полями ввода и график чувствительности в ней (прогон 49 значений поля через расчёт, `window.__dhSamp` глушит анимацию цифр, ключ `dh-sens`) |
| `app/shell/app.css` | все стили. Файл слоями по версиям, **последнее правило выигрывает**: новые правки дописывать в конец отдельным блоком с комментарием версии |
| `app/shell/newcalcs.js` | 21 расчёт только для приложения (в том числе отдача ВЗД, слепая зона датчиков, батарея телесистемы), у каждого текст `how` с источниками |
| `app/shell/game.*` | игра «Вахта» |
| `app/scripts/setup-native.mjs` | `cap add`, иконки, версия, правки манифеста/plist, minSdk 26, `setTextZoom(100)` в MainActivity |
| `app/resources/` | официальная иконка и заставка (знак `#f2a541`, фон `#080d10`) |

Палитра как на сайте. Тёмная тема: фон `#080d10`, панель `#101b21`, линия `#1f3038`, текст `#eef3f5`,
приглушённый `#9fb0b6`, акцент `#f5a524`. Светлая: `#f4f6f6`, `#fff`, `#d3dcdc`, `#10232a`, `#4d626a`, `#c26f06`.
Один акцентный цвет, без радужных плиток.

localStorage: `dh-theme`, `dh-size`, `dh-fx`, `dh-in:{slug}`, `dh-mode:{slug}`, `dh-wells`, `dh-well`, `dh-hist`,
`dh-fav`, `dh-recent`, `dh-game`, `dh-sens`.

## Порядок работы
1. Правки в `app/shell/*` или `app/mk_app.py`.
2. `python3 app/mk_app.py` из корня (нужен `dist/`; если менялся сайт, сначала `python3 build.py`).
3. Проверить в браузере с экраном телефона: `cd app/www && python3 -m http.server 8765`, затем
   `node tests-app/screens.js` (Playwright, 360×780). Смотреть скриншоты и что `scrollWidth == innerWidth`
   на всех экранах: горизонтальный вылет текста вправо уже был больной темой.
4. Поднять версию в `app/package.json` (сейчас 2.3.0, каждый выпуск +1 в последней цифре).
5. Коммит и push в `main`. Workflow `.github/workflows/android-apk.yml` сам собирает debug-APK при изменениях
   в `app/**`, публикует pre-release `v{версия}-build{N}` и кладёт APK в ветку `apk`.
   Забрать файл: `git fetch --depth 1 origin apk && git archive FETCH_HEAD | tar -x`.

Локально APK: `cd app && npm install && npm run setup && npm run apk` (Node 22, JDK 21, Android SDK).

## Грабли, на которые уже наступали
- Не копировать поверх репозитория старые копии файлов: так однажды затёрся рабочий workflow и сборка упала.
- Прокрутка: `html`/`body` не должны быть контейнером прокрутки, `overscroll-behavior` не `none`, у canvas
  `touch-action: pan-y`. Иначе на Android страница не листается.
- Гриды списков только `minmax(0,1fr)`, длинные подписи с переносом или ellipsis, у `.home` `overflow-x: clip`.
- Системный размер шрифта Android ломает вёрстку, поэтому `setTextZoom(100)`; размер выбирается в «Ещё».
- В однострочном JS не ставить `//`-комментарии, только `/* */`.
- Пользователь не хочет перегруженный главный экран и акцент на скважине: это калькулятор. Кнопки нижней панели
  расчёта одинаковые, «Сохранить» без заливки.

## Онлайн-данные
Сервис live.drillharmony.com (WITS0/WITSML) живёт отдельно на VPS в `/opt/dh-live`, служба `dh-live`.
В приложении открывается во встроенном окне (`@capacitor/inappbrowser`). Его код в этот репозиторий не входит.
